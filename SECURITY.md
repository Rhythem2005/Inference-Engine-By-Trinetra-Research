# Reporting a security issue

Use **Security → Report a vulnerability** on GitHub when private vulnerability reporting is enabled. If the option is unavailable, ask for a private reporting channel through the [Trinetra AI Research website](https://trinetra-research.vercel.app/). Keep sensitive details out of public issues and pull requests.

Include the affected version or commit, your platform, what you observed, and any steps that help reproduce the issue. Remove credentials, personal data, prompts, and private model files from anything you share.

The browser and API are intended for local use. The API has no authentication. Keep both services bound to loopback and use matching model files from a trusted source.
